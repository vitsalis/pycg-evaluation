A traced call of a class maps to an `__init__` only with the proof of
evaluation/README.md ("The proof of a constructor"). The proof reads the
syntax of the modules of the class's hierarchy and makes one assumption,
the closed-class assumption: no other code changes a class after its
`class` statement (a helper or another module that receives the class and
sets its attributes, `setattr` with a computed name, a decorator applied
by hand elsewhere, a library's `__set_name__`, another module that rebinds
a name of a module of the hierarchy, code that reads or writes another
frame's namespace). A project that breaks it gets a wrong mapping for
the classes concerned, for every tool alike. Two stated limits of the
proof have the same consequence: a namespace function reached through an
import alias (`from builtins import locals as namespace`) is not seen, nor
a rebinding behind an import alias (`from m import Base as Imported` while
the write names `Base`) or of a prefix of a dotted name (`base.inner =
other` before `class Child(base.inner.Base)`).

So the table measures recall over the traced edges that are mapped,
given the mapping. The share of traced edges counted apart does not bound
the errors among the mapped edges, and the mapping treats every tool
alike, but equal treatment does not prove equal bias.
